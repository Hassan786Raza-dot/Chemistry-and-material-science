# User Guide

## Start here

Run `npm install`, then `npm run dev`. The landing page presents a two-step workflow. Select **Run demo** to populate a realistic free-radical example, or replace the values with your own planning or measured conditions. The form checks units and broad physical ranges before the run.

## Understand the status labels

The result banner reads **Exploratory screening estimate**. This is intentional. The local model produces a reproducible numerical curve, but the repository has no calibration dataset and does not model the full reaction mechanism. Treat the curve as a scenario for planning measurements, not as an observation or validated prediction.

The diagnostics panel lists every simplifying assumption. The most important limitations are the pseudo-first-order conversion curve, heuristic use of reactivity ratios, idealized molecular-weight proxy, and omission of oxygen inhibition, diffusion limitation, heat transfer, solvent quality, termination modes, and side reactions.

## Use live enrichment safely

The app sends each monomer name to PubChem and searches Crossref for metadata. A successful response shows the source URL and retrieval time. An unsuccessful response is shown as a warning and does not replace missing chemical facts with guesses. Check every match manually, especially for salts, stereoisomers, mixtures, trade names, and polymer repeat units.

## Export and record provenance

Use **Export CSV** for the numeric table. Record the Git commit, input values, browser date, source URLs, and whether metadata lookups were live or unavailable. Preserve the exported file with the analysis notebook. If the run informs a paper, report that the curve was generated by the repository's deterministic screening model and provide an independent validation protocol.

## What to do before laboratory use

First confirm chemical identity and intended reaction mechanism from primary literature and supplier or safety documentation. Then collect time-resolved conversion measurements with independent batches, analytical calibration, blanks, detection limits, uncertainty, temperature records, and polymer characterization such as SEC/GPC where applicable. Fit candidate models to raw data using pre-specified rules, inspect residuals and parameter uncertainty, and test predictions on held-out experiments.

The interface does not perform a safety assessment, synthesis authorization, environmental-risk assessment, or regulatory check. Those decisions require qualified professionals and authoritative, context-specific evidence.
