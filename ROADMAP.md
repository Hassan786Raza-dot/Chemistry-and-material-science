# Roadmap

## Near term: 1–2 months

Add a versioned input/output JSON Schema, deterministic clock injection for tests, browser export of the complete provenance record, and continuous integration for type-checking, tests, build, and demo execution. Add an expert-reviewed benchmark of input edge cases and a usability review with polymer researchers.

Define a raw experimental-data contract with units, independent-batch identifiers, blanks, calibration metadata, analytical uncertainty, and exclusion reasons. Do not add model fitting until a real, curated dataset is available.

## Medium term: 3–6 months

Add a separate analysis package for measured conversion data. It should support unit-safe calculations, replicate-aware uncertainty, pre-registered exclusion rules, residual diagnostics, parameter confidence intervals, alternative model comparison, and held-out validation. Add literature evidence capture with search terms, retrieval dates, DOI, quoted support, and human review status.

Add cheminformatics validation for molecular graphs, formal charge, valence, stereochemistry, and repeat-unit representation. Keep name lookup separate from identity confirmation.

## Long term: research collaboration

Integrate validated mechanistic kinetic models and simulation workflows only with pinned software, input decks, convergence criteria, benchmark systems, and expert-reviewed parameters. Create a public benchmark containing raw observations, failed runs, batch metadata, and persistent identifiers. Add safety, toxicity, and regulatory modules only through authoritative jurisdiction-specific sources and professional review.
