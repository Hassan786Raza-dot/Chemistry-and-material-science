# Limitation-Complete Implementation Report

## Release decision

The repository now treats the absence of experimental evidence as a software state, not as a hidden limitation. It has three explicit evidence concepts: exploratory screening, measured fit, and externally validated. Only the first two are implemented; the third cannot be truthfully assigned without an independent benchmark and pre-specified acceptance criteria.

## Controls implemented

The deterministic screen now records a model version, stable input hash, assumptions, warnings, source timestamps, and an explicit exploratory status. The UI places this status next to the chart and exposes the input hash and record version. Unsupported reaction types, malformed inputs, ambiguous chemical lookups, missing live services, and model omissions are surfaced as warnings rather than silently accepted.

A new measured-data gate accepts a constrained CSV schema, rejects missing or malformed observations, requires at least six time points, performs a deterministic temporal holdout, reports RMSE, R², residuals, fitted parameter uncertainty, and a confidence interval, and labels the result `measured-fit`. The workflow still warns that temporal holdout is not independent-batch validation and does not claim mechanism validity.

## Limitation coverage

`LIMITATION_REGISTER.md` maps each known scientific, methodological, statistical, computational, and practical limitation to an implemented mitigation and residual next step. `AUDIT_CHECKLIST.md` provides a rerunnable release gate. The user guide explains how to preserve raw data, pre-register exclusions, distinguish replicates, and validate externally. No safety, toxicity, environmental-fate, regulatory, synthesis, or treatment-performance claim is generated by the application.

## Residual-risk statement

The system is suitable for transparent screening and measured-data exploration. It is not yet suitable for claiming externally validated scientific evidence because this repository still lacks a real experimental calibration set, independent batches, polymer characterization, chemistry-specific mechanism validation, and expert-reviewed acceptance criteria. That residual boundary is intentional, visible, tested, and documented rather than concealed. The correct path to a stronger evidence tier is recorded in `ROADMAP.md` and `OPEN_ISSUES.md`.
